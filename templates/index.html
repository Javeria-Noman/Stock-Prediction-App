How a prediction is made

The same four steps run every time you press the button.

  1. Download

    Recent daily prices and volume are fetched with yfinance.

  2. Build features

    Previous close, 5, 10 and 20-day averages and daily change, using only past data.

  3. Run two models

    Linear Regression and Random Forest each estimate tomorrow's close.

  4. Show the result

    You see the latest close, each prediction and the difference.

Project report

Problem and goal

Predict the next trading day's closing price from about five years of daily Open, High, Low, Close and Volume data, downloaded with yfinance.

Method

Features are the previous close, 5, 10 and 20-day moving averages, and daily change, all built from past data only. The data is split chronologically 80/20, and the scaler is fit on training data only. Linear Regression and a tuned Random Forest were compared.

Why Random Forest can score poorly

Tree-based models cannot predict values above the range they saw in training. If test-period prices rise past that range, predictions flatten and under-predict, which pushes R² down. Predicting daily returns instead of prices is the usual fix.

Limitations

Only price and volume are used. News, earnings and sentiment are not. Tomorrow's price is already close to today's, so compare any model with the naive baseline of "tomorrow equals today". Good test scores do not guarantee future accuracy.

Educational project. Predictions are experimental and are not financial advice.
